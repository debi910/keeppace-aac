KeepPace benchmark

Back to the keyboard

Replays held-out replies from Keith Vertanen's crowdsourced AAC-style dialogues and counts how many selections each input method needs, assuming the user always picks the right suggestion when it is shown. Get the data file from keithv.com/pub/aacdialogue (turk-dialogues.txt); it stays on your computer.

Words per minute at one selection per second

Eye-gaze users typically need about a second per selection. Higher is better.
